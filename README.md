## 👨‍💻 About

I'm **Rahul Dewal**, a Frontend / React Developer focused on building
scalable, maintainable, and user-friendly web applications.

My primary expertise is in:

- React
- JavaScript
- TypeScript
- Redux
- Responsive UI development
- Component architecture
- REST API integration

I'm also expanding my expertise toward **full-stack JavaScript development**
with a focus on the MERN ecosystem.

This portfolio is designed to demonstrate not only the technologies I use,
but also how I approach frontend engineering, product requirements,
architecture, maintainability, and user experience.

---

## 🎯 Purpose of This Portfolio

This website serves as my professional developer portfolio and is designed
to give recruiters, hiring managers, and other developers a quick overview of:

- My professional experience
- The type of applications I build
- Selected production projects
- My engineering approach
- My technical toolkit
- My career direction
- Ways to connect with me

Rather than being only a collection of projects, the portfolio is structured
around **how I think and build software**.

### ⚡ Modern Frontend

- React-based component architecture
- Vite-powered development and production builds
- Tailwind CSS for styling
- Reusable theme-based design system
- Responsive layouts
- Mobile-first approach

---

### ✨ Animations & Interactions

Framer Motion is used for subtle interactions and animations including:

- Section reveal animations
- Element entrance animations
- Hover interactions
- Floating UI elements
- Mobile navigation transitions
- Scroll-based animations

Animations are intentionally kept subtle so they enhance the experience
without distracting from the content.

---

### 📱 Responsive Design

The portfolio is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

The layout, navigation, typography, cards, buttons, and content spacing
adapt according to the available screen size.

## 🎨 Design System

The portfolio uses a dark, engineering-focused visual system.

### Brand Colors

- **Primary:** Cyan
- **Secondary:** Blue
- **Success:** Lime / Green

### UI Direction

- Dark backgrounds
- Subtle borders
- Soft ambient gradients
- Minimal glass effects
- Rounded cards
- Monospace elements for technical context
- Cyan/blue accent interactions

The goal is to create a visual identity that feels like a **modern software
engineering portfolio** rather than a generic template.
